## Detailed Retro/Cyberpunk Design Theme Explanation

This section provides a comprehensive breakdown of the retro/cyberpunk aesthetic currently implemented in the portfolio, based on the design system defined in the CSS.

### Color System & CSS Variables

The design uses a carefully curated color palette stored as CSS custom properties:

**Core Colors:**
- `--retro-black: #0a0a0a` - Near-black background (#0a0a0a, not pure black for softer appearance)
- `--retro-dark: #1a1a2e` - Dark blue-gray for secondary backgrounds
- `--retro-darker: #16213e` - Darker blue-gray variant

**Accent Colors (Neon/Vibrant):**
- `--retro-green: #39ff14` - Primary neon green (Matrix-inspired)
- `--retro-green-soft: #7fff00` - Softer green variant
- `--retro-cyan: #00d9ff` - Bright cyan (tech/cyber aesthetic)
- `--retro-blue: #00a8ff` - Vibrant blue
- `--retro-orange: #ff6b35` - Energetic orange
- `--retro-yellow: #ffd700` - Gold/yellow accent
- `--retro-yellow-soft: #ffed4e` - Softer yellow variant
- `--retro-purple: #b19cd9` - Muted purple
- `--retro-pink: #ff1493` - Hot pink accent

**Text Colors:**
- `--retro-text: #e0e0e0` - Primary text (light gray for readability)
- `--retro-text-dim: #b0b0b0` - Secondary/dimmed text

### Typography

**Font Family:** JetBrains Mono (Monospace)
- Creates a code/terminal aesthetic
- Font weights: 400 (regular), 500 (medium), 600 (semibold), 700 (bold)
- Monospace fonts evoke programming, terminals, and retro computing
- Fallback fonts: 'Courier New', 'Monaco', 'Menlo', monospace

### Background Layers & Atmosphere

The design uses multiple layered backgrounds to create depth and atmosphere:

1. **Base Layer (z-index: -4)**
   - Subtle noise texture with fractal noise pattern
   - Creates a grainy, authentic retro feel
   - Very low opacity (0.015-0.02) for subtlety

2. **Diagonal Pattern Layer (z-index: -3)**
   - Repeating diagonal line patterns at 45° and -45° angles
   - Moving animation (25s infinite linear)
   - Creates dynamic visual texture

3. **Gradient Layer (z-index: -2)**
   - Multiple linear gradients at different angles
   - Animated shifting (20s ease-in-out infinite)
   - Subtle color washes in green, cyan, and orange

4. **Pattern Layer (z-index: -1)**
   - Animated grid pattern (60x60px squares)
   - Moving grid creates sense of motion
   - Radial gradient overlays with colored blobs (green, cyan, orange, yellow)
   - Gradient pulse animation (20s ease-in-out)

5. **Corner Accents (z-index: -1)**
   - Radial gradients at each corner (top-left, top-right, bottom-left, bottom-right)
   - Different colors per corner (green, cyan, orange, yellow)
   - Pulse animation (8s ease-in-out infinite)

6. **Floating Geometric Shapes (z-index: -1)**
   - 4 floating square shapes with borders
   - Each shape has different size, position, and color
   - Continuous floating animation (20s infinite ease-in-out)
   - Very low opacity (0.03-0.05) for subtlety

7. **Vignette Effect (z-index: -1)**
   - Radial gradient creating darker edges
   - Adds focus to center content
   - Creates depth and cinematic feel

8. **Scanline Effect (z-index: 9999)**
   - CRT monitor scanline effect (repeating horizontal lines)
   - Only visible on hover (subtle interaction feedback)
   - Creates authentic retro computer screen aesthetic

### Text Effects & Styling

**Text Glows:**
- Multiple glow variations using text-shadow:
  - `.text-glow` - Standard green glow
  - `.text-glow-strong` - Stronger green glow for emphasis
  - `.text-glow-cyan` - Cyan glow variant
  - `.text-glow-yellow` - Yellow glow variant
  - `.text-glow-orange` - Orange glow variant
- Glows use layered shadows (multiple offsets) for depth

**Gradient Text:**
- `.gradient-text` - Orange to blue gradient
- `.gradient-text-green` - Green to cyan gradient
- Uses `-webkit-background-clip: text` for gradient text effect

**Glitch Effect:**
- Subtle glitch animation on hover
- Small random translations (-1px to 1px)
- Creates digital/cyberpunk aesthetic
- Color shift to green on hover

**Terminal Cursor:**
- Blinking cursor animation (`▊` character)
- Used after name/headings to create terminal/code aesthetic
- 1.2s infinite blink animation

### Button Styles

**Base Retro Button (`.retro-btn`):**
- Transparent background with colored border
- Uppercase text with letter-spacing (1.5px)
- Hover effect: Gradient fill slides in from left
- Glow effect on hover (box-shadow)
- Slight lift on hover (translateY(-2px))
- Transition: 0.3-0.4s ease

**Button Variants:**
- `.retro-btn-yellow` - Yellow accent variant
- `.retro-btn-gradient` - Solid gradient background (orange to blue)
- All maintain consistent hover behaviors

### Card Styles

**Base Retro Card (`.retro-card`):**
- Subtle border with colored glow
- Transparent background with slight color tint
- Double border effect on hover (outer border becomes visible)
- Lift effect on hover (translateY(-6px))
- Enhanced glow on hover (multiple shadow layers)
- Inset shadow for depth

**Card Variants:**
- `.retro-card-cyan` - Cyan-themed card
- `.retro-card-orange` - Orange-themed card
- Each variant uses its respective color in borders, backgrounds, and glows

### Profile Image Styling

**Retro Profile Image Effects:**
- Slight scale-up (1.1x) for visual interest
- Color filters: contrast (1.15), brightness (0.9), saturation (0.85), sepia (0.15)
- Creates retro/vintage photo effect

**Scanline Overlay:**
- Animated scanlines over image (repeating horizontal lines)
- Moving animation (8s linear infinite)
- Mix-blend-mode: overlay for integration
- Opacity: 0.6 (adjustable on hover)

**Color Mask Overlay:**

- Creates cyberpunk color grading effect

**Image Wrapper:**
- Gradient border (cyan to green)

- Creates "framed in light" effect

**Text Selection:**
- Orange-tinted selection background (rgba(255, 107, 53, 0.3))
- Maintains text readability

**Links:**
- Colored text (green by default)
- Animated underline on hover (width transition)
- Glow effect on hover

### Section Styling

**Section Numbers:**
- Colored numbers (e.g., "01.", "02.", "03.")
- Color variations: green, cyan, orange, yellow
- Bold font weight, letter-spacing for emphasis

**Accent Lines:**
- `.retro-line` - Simple gradient line (transparent → color → transparent)
- `.retro-line-gradient` - Multi-color gradient line (orange → blue)
- Used as decorative dividers between sections

### Animation Principles

**General Animation Characteristics:**
- Smooth transitions (0.3s - 0.6s ease)
- Infinite loops for background elements (20s - 25s duration)
- Staggered animations for lists/collections
- Ease-in-out timing functions for natural motion

**Key Animations:**
- `gridMove` - Grid pattern translation (20s linear)
- `gradientPulse` - Gradient scale and opacity (20s ease-in-out)
- `backgroundShift` - Multi-point transform (20s ease-in-out)
- `diagonalMove` - Diagonal pattern translation (25s linear)
- `noiseFlicker` - Subtle opacity flicker (0.1s infinite)
- `cornerPulse` - Corner gradient scale (8s ease-in-out)
- `float` - Geometric shape movement (20s ease-in-out)
- `subtleGlitch` - Text glitch effect (0.3s ease-in-out)
- `blink` - Cursor blink (1.2s infinite)
- `subtlePulse` - General pulse effect (3s ease-in-out)
- `scanlineMove` - Scanline translation (8s linear)
- `gradientShift` - Background gradient movement (15s ease)

### Design Philosophy

**Retro/Cyberpunk Aesthetic Goals:**
1. **Nostalgia** - References to 80s/90s computing, terminal interfaces, CRT monitors
2. **Futuristic** - Neon colors, glows, and digital effects suggest advanced technology
3. **Code-First** - Monospace fonts, terminal cursors, and code-like styling emphasize developer identity
4. **Atmospheric** - Multiple background layers create immersive, layered environment
5. **Interactive** - Hover effects, animations, and transitions create engaging experience
6. **High Contrast** - Bright neon colors on dark background ensure visibility and impact
7. **Layered Depth** - Multiple z-index layers create visual hierarchy and depth
8. **Subtle Motion** - Continuous but subtle animations keep page alive without distraction

**Visual Hierarchy:**
- Dark background allows neon accents to "pop"
- Multiple glow layers create depth
- Color coding helps organize information (green, cyan, orange, yellow for different sections)
- Typography (monospace) reinforces technical/professional identity

**Balance:**
- Bold colors balanced with subtle backgrounds
- Intense effects (glows) balanced with low-opacity overlays
- Motion balanced with static elements
- Retro aesthetic balanced with modern web standards

### Design Implementation Notes

- All animations use `transform` and `opacity` for performance (GPU-accelerated)
- Background layers use `pointer-events: none` to avoid interaction issues
- Fixed positioning for background layers ensures they stay behind content
- CSS custom properties enable easy theme customization
- Media queries adjust button sizes for mobile responsiveness
- Transitions use `ease` and `ease-in-out` for natural motion
- Multiple box-shadow layers create realistic glow effects
